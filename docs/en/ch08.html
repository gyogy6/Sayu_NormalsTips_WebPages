8. Normal maps

A normal map is built on top of the vertex normals.

Base vertex normals
Triangles: · Drag the view to turn it.
  • A normal map tilts the normal a little, on top of the vertex normals (and the UV directions).
  • Turn on “Read green (Y) reversed” and the bumps flip up and down, so the lighting looks wrong.
  • Set the base to “Flat” and the faces show even with the same normal map. When the base normals change, the result changes.
