9. Things to watch on export and import

Normals can be rebuilt along the way.

Normals after import
Triangles: · Drag the view to turn it.
  • A: the normals stored in the file (here, custom normals that clean up the shading) are used as is.
  • B: if the importer recomputes them, the custom normals are lost and the blotchy shading returns.
  • C: recomputing with a small split angle turns smooth areas into corners.
  • D: if the mesh is mirrored but the face order (vertex order) is not fixed, the normals point inward and the lighting is reversed.
