1. 법선이란

면의 방향과 빛의 각도로 밝기가 정해지는 원리.

N과 L 사이의 각도 θ N·L = cos θ 밝기 max(0, N·L) 툰 (1 = 밝음, 0 = 그림자)
  • N은 면의 법선(면에 수직이고 길이가 1인 방향), L은 빛이 오는 방향입니다.
  • 밝기는 max(0, N·L) = max(0, cos θ)입니다. 빛이 정면이면 1, 옆이면 0, 뒤에서 와도 0입니다.
  • 툰은 N·L이 임계값보다 큰지 아닌지로 두 가지 색으로 나눕니다. 임계값 근처에서는 아주 작은 방향 차이로 색이 바뀝니다.
  • '면의 기울기'와 '빛의 방향' 중 무엇을 움직여도, 밝기는 두 각도의 차이로만 정해집니다.
