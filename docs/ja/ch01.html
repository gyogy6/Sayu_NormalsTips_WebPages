1. 法線とは

面の向きと、光との角度で明るさが決まるしくみ。

N と L の角度 θ N·L = cos θ 明るさ max(0, N·L) トゥーン（1 = 明るい、0 = 影）
  • N は面の法線（面に垂直な、長さ 1 の向き）、L は光が来る向きです。
  • 明るさは max(0, N·L) = max(0, cos θ)。光が真正面なら 1、横からなら 0、後ろからでも 0 です。
  • トゥーンは N·L がしきい値より大きいかどうかで 2 色に分けます。しきい値の近くでは、わずかな向きの差で色が入れ替わります。
  • 「面の傾き」と「光の向き」のどちらを動かしても、明るさは 2 つの角度の差だけで決まります。
